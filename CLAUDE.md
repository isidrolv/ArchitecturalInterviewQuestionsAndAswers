# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Repository Purpose

This is a **content-only repository** — a curated collection of architectural interview questions and their answers. There is no source code, build system, or test suite.

## Content Conventions

- Each entry must include both a **question** and a **thorough answer**.
- Topics should cover software architecture: system design, design patterns, scalability, microservices, distributed systems, cloud architecture, and trade-offs.
- Answers should be practical and interview-appropriate — concise enough to deliver verbally, but complete enough to demonstrate depth.
- Do not duplicate questions already present.
- Follow the formatting structure already established in README.md. Keep new entries consistent with existing ones.
